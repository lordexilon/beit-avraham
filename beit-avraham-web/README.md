# Beit Avraham

Aplicación educativa independiente de `../sca-studio`.

## Ejecutar

Requiere Node.js 20.9 o superior.

```sh
npm install
npm run dev
```

Abrir http://localhost:3001. Para verificar: `npm run typecheck` y `npm run build`.

## Nodo N1

Identidad con logo local, folio responsive de tres columnas inspirado en el HTML aportado, navegación con estados vacíos, selección de fragmentos ilustrativos, tamaño de lectura y notas temporales. Fuentes tipográficas Google con alternativas locales si no hay conexión.

La vista está marcada como demostración. No incluye video real, transcripción real, recuperación, streaming, autenticación ni persistencia de notas. No contiene métricas inventadas ni dictámenes halájicos. El panel Javrutá permite explorar visualmente el contexto seleccionado; su formulario permanece deshabilitado hasta integrar fuentes.

N2-N5 requieren revisión y aprobación según el protocolo STRICT. No se ha desplegado ni escrito en Supabase.
